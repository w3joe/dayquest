# Image prompts: shared

Generated with Codex's built-in `image_gen` tool (Codex CLI on Shawn's ChatGPT login, no API key) via `tools/gen.sh`. Every prompt is the shared style prefix + the asset text + an ending (object or tile), identical to shadwell-25d. Below, every `image_gen` call for this folder is copied verbatim from the Codex session records, in time order, retries included.

Shared style prefix:

> Original pixel-art game asset for a 2010s handheld (DS-era) style top-down RPG. Steep top-down 3/4 view (camera high, looking down at about 60 degrees, so we see the front face and a sliver of the top). Clean crisp chunky square pixels, flat colour shading with 2-3 tones per material, absolutely no dithering, no noise, no gradients, no anti-aliasing blur. Dark 1px outlines around shapes. Bright cheerful palette (teal-green grass, sandy paving, warm red-brown bricks). Light comes from the top-left. Entirely original design, not copied from or imitating any existing game, character or logo.

Object ending:

> Show ONE isolated object, centred, whole object visible with margin around it, on a perfectly flat solid pure magenta (#FF00FF) background. No cast shadow on the ground, no ground plane, no scenery, no border, no extra text or labels.

Tile ending:

> This is a single seamless repeating ground texture tile viewed straight down (orthographic, no perspective), filling the entire square image edge to edge, designed on a 16x16 grid of big pixels so it tiles seamlessly on all four sides. No border, no objects, no text. Square 1024x1024.

## Notes

skyline is drawn as a repeating backdrop behind the far side of Westminster and St Giles High Street, and on the bus transit; process.py blends it 22% towards the sky colour so it reads as a few streets away. The other shared sprites (Shawn's walk sheet, the Shadwell tiles and props) are copied unchanged from ../shadwell-25d/assets; their prompts are in ../shadwell-25d/assets/prompts.md. The player interaction strips (act_eat, act_drink, act_sit, act_photo, act_wave, act_point) were generated with ../shadwell-25d/assets/raw/shawn_walk.png attached as the character reference, and fx (four effect icons) without it; shared/make_actions.py slices them into actions.png (4 cols x 6 rows of 32x48 cells: eat 4, drink 3, sit 2, photo 2, wave 3, point 2; waist-up eat/drink frames have the waist at y=36) and fx_steam (16x24), fx_sparkle, fx_heart, fx_flash (16x16).
